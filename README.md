## 🌱 요즘 보고 있는 것

- **Go** — Java 밖에서 서버를 처음부터 다시 세워 보는 중. `speakCode` 는 채팅 · 파일 공유까지 끝냈고, 다음은 음성 통화(WebRTC)입니다.
- **Kotlin Multiplatform** — Android 앱을 넘어, 하나의 코드로 iPhone 까지 내보내는 중입니다.
- **로컬 LLM** — 외부 API 없이 내 GPU 로 추론 · 번역까지 닫는 구성을 다듬고 있습니다.
- **Unity · C#** — 3D 놀이공원 경영 시뮬레이션(ParkSim)을 설계 마치고 구현에 들어갑니다.
- **데이터 파이프라인** — Kafka · Elasticsearch · Cassandra 를 인프라로 다뤄 왔고, 이제 그 위의 처리 · 모델링 쪽을 봅니다.
